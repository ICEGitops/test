정보통신공학과 학생 여러분을 위한 자동화 배포 시스템입니다.
복잡한 인프라 설정 없이, 소스 코드만 작성하면 자동으로 도메인 연결(SSL)과 배포가 완료됩니다.

✨ 주요 기능

  • Automated CI/CD: GitHub Push 한 번으로 빌드부터 배포까지 자동화
  • Custom Domain: iceweb.hufs.ac.kr 서브 도메인 자동 할당
  • SSL/TLS Security: Let's Encrypt 인증서 자동 적용 (HTTPS)
  • ArgoCD Sync: GitOps 방식의 투명한 인프라 관리

🚀 시작하기 (Quick Start)

나만의 프로젝트를 배포하는 방법은 아주 간단합니다.

  1. Code: 본인의 GitHub 계정에 Public Repository를 생성하고 코드를 작성합니다.
  2. Push: 작성한 코드를 GitHub에 `git push` 하여 업로드합니다.
  3. Contact: 관리자에게 레포지토리 주소를 전달하면, GitOps 연동 후 배포가 시작됩니다!

📚 CI/CD가 무엇인가요?

CI (Continuous Integration)와 CD (Continuous Deployment)는 개발자가 코드를 작성하고 배포하는 과정을 자동화하는 기술입니다.

  • 이전에는... 코드를 다 짜고, 서버에 접속해서, 파일을 전송하고, 서버를 재시작해야 했습니다. 😫
  • 이제는! 코드를 Push하기만 하면, GitHub Actions가 알아서 테스트하고 서버에 배포해줍니다. 😎

본 서비스는 ArgoCD를 활용한 GitOps 방식을 사용하여, Git 레포지토리의 상태와 실제 서버의 상태를 항상 동일하게 유지합니다.
