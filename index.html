정보통신공학과 학생 여러분을 위한 자동화 배포 시스템입니다.
복잡한 인프라 설정 없이, 소스 코드만 작성하면 자동으로 도메인 연결(SSL)과 배포가 완료됩니다.

✨ 주요 기능

  • Automated CI/CD: GitHub Push 한 번으로 빌드부터 배포까지 자동화
  • Custom Domain: iceweb.hufs.ac.kr 서브 도메인 자동 할당
  • SSL/TLS Security: Let's Encrypt 인증서 자동 적용 (HTTPS)
  • ArgoCD Sync: GitOps 방식의 투명한 인프라 관리

🚀 시작하기 (Quick Start)

나만의 프로젝트를 배포하는 방법은 간단합니다.

  1. Invitation: 먼저 관리자에게 ICEGitops Organization 초대를 요청하세요.
  2. Create Repo: 초대받은 Organization 내에 Public Repository를 생성합니다.
  3. Push & CI: 코드를 작성하고 Push하여 CI 빌드가 성공하는지 확인합니다.
  4. Contact: 관리자에게 배포 요청을 보내면, 최종적으로 서비스가 오픈됩니다.

📚 CI/CD란 무엇인가요?

"코드를 수정하고 저장(Push)만 하세요. 나머지는 시스템이 자동으로 처리합니다."

  • ⚡ Continuous Integration (CI)
    여러분이 작성한 코드가 서버에서 잘 작동하는지 자동으로 테스트합니다.
  • 🚀 Continuous Deployment (CD)
    테스트가 통과되면, 실제 웹사이트에 자동으로 배포합니다. (약 3~5분 소요)

이 모든 과정은 GitHub Actions와 ArgoCD를 통해 투명하고 안전하게 관리됩니다.
