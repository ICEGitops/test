정보통신공학과 학생 여러분을 위한 자동화 배포 시스템입니다.
복잡한 인프라 설정 없이, 코드만 작성하면 자동으로 도메인 연결과 SSL 보안 적용까지 완료됩니다.

✨ 주요 기능

  • Automated CI/CD: GitHub Push 한 번으로 빌드부터 배포까지 자동화
  • Custom Domain: iceweb.hufs.ac.kr 서브 도메인 자동 할당
  • SSL/TLS Security: Let's Encrypt 인증서 자동 적용 (HTTPS)
  • ArgoCD Sync: GitOps 방식의 투명한 인프라 관리

🚀 시작하기

지금 바로 자신만의 프로젝트를 시작해보세요. 템플릿을 복사하고, 코드를 작성하면 끝입니다. 인프라는 저희가 담당합니다.
